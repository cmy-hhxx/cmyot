## 2. 模块边界与所有权

| 模块 | 拥有什么 | 不拥有什么 | 对外入口 |
|---|---|---|---|
| `domain/order` | 订单状态机、幂等规则 | 数据库、HTTP | `domain/order/index.ts` |
| `infra/order-repo` | 持久化实现 | 业务规则 | `OrderRepository` 接口实现 |

## 3. 接口契约

| 接口 | 签名 / 类型 | 错误语义 | 幂等 / 超时 | 实现方 | 调用方 |
|---|---|---|---|---|---|
| `OrderRepository` | `save(order): Promise<Result<Order, RepoError>>` | 不抛异常，返回 Result | 按 `orderId` 幂等 | infra | domain |

**契约规则**：

- 跨模块只依赖接口 / 类型，不依赖实现（禁止 `import { PgOrderRepo }` 进 domain）
- 错误用统一类型，禁止 throw 字符串 / 吞异常
- 返回值显式：成功 / 失败 / 未知三种情况都要有语义

## 4. 依赖方向规则（必须可执行）

- **允许**：`routes → app → domain`；`infra → domain`（实现 domain 定义的接口）
- **禁止**：`domain → infra`；`domain → 框架`；任何循环
- **例外登记**：<文件 + 原因 + 计划移除时间>
- **检查命令**：`ARCH_CHECK_CMD=<...>`（写进 `handoff.env`）
