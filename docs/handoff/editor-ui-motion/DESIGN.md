## 6. 不变量（Must / Never）

**Must**
- 所有颜色 / 时长 / 间距来自令牌，禁止裸值
- 所有可交互元素有 `:focus-visible`，且焦点环可见（对比度 ≥ 3:1）
- 动画不阻塞首帧；首屏关键元素延迟 ≤200ms
- `prefers-reduced-motion: reduce` 时：位移类动画降级为 opacity 交叉淡入，时长 ≤120ms

**Never**
- 不引入第四条缓动曲线
- 不用 `transition: all`
- 不用 `!important`
- 不在滚动回调里同步读布局（`offsetHeight` 等）
- 动效循环不出现"回弹/overshoot"，除非动效表里明写

## 7. 禁止的简化（含原因）

> 这一节专门防执行者"顺手合并"。

- <例：不要合并 `#bg-layer` 和 `#fg-layer` 两个 SVG group——它们分别以 0.3x / 1x 速率做视差>
- <例：不要把手写 cubic-bezier 换成 `ease-in-out`——曲线差异就是这个动效的质感来源>
- <例：不要把 3 个交错的入场动画合并成一个——交错节奏是设计的一部分>
